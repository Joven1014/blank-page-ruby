# Blank Page — Ruby edition

A dependency-free Ruby version of Blank Page, built with Ruby's bundled WEBrick server.

## Run

```sh
ruby app.rb
```

Open `http://127.0.0.1:4567`. Enter a search phrase to use Google or enter a domain/full URL to go there directly.

Optional environment variables:

```sh
PORT=3000 BIND=0.0.0.0 ruby app.rb
```
